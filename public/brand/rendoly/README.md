# Rendoly logo

Rendoly (one L; domain: rendoly.com) is the planned self-serve instant-estimator product for contractors. Chosen mark: the **roofline r** — a roof
over a lowercase "r". The wordmark is Plus Jakarta Sans ExtraBold (800), tracked −0.035 em, converted to outlines, so
the SVGs need no font.

## Files

| File | Use |
| --- | --- |
| `rendoly-logo.svg` / `rendoly-logo-1200.png` | Primary lockup (blue tile + navy wordmark) on light backgrounds |
| `rendoly-logo-reversed.svg` / `rendoly-logo-reversed-1200.png` | Lockup on dark backgrounds (lime roof, white r and wordmark) |
| `rendoly-mark.svg` | The mark alone: blue rounded tile, white roof and r. Avatars, app icon |
| `rendoly-mark-reversed.svg` | The mark without a tile, for dark backgrounds |
| `rendoly-mark-square.svg` | Full-bleed square tile, for platforms that round the corners themselves (iOS, app stores) |
| `rendoly-wordmark.svg` | The word alone, navy |
| `rendoly-icon-512.png`, `rendoly-icon-192.png` | Web app manifest icons |
| `rendoly-apple-touch-icon.png` | 180 × 180, full-bleed |
| `rendoly-favicon-32.png`, `rendoly-favicon-16.png` | Favicons |

## Colors

| Name | Hex | Use |
| --- | --- | --- |
| Rendoly Blue | `#2F5BFF` | Tile, primary accent |
| Ink | `#0E1626` | Wordmark on light, dark backgrounds |
| Lime | `#C4F135` | Roof on dark backgrounds, highlights |
| Mist | `#F4F6FA` | Light backgrounds |

## Rules

- Keep clear space around the lockup of at least half the tile's width.
- Don't recolor the wordmark outside Ink or white, stretch it, or retype it in another font.
- Smallest sizes: lockup 120 px wide, mark 16 px.
